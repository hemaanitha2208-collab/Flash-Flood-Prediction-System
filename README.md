# Disaster Management Dashboard

This is the same Figma Make prototype source, kept visually unchanged. The Figma-specific configuration files were removed so the project is easier to understand and run as a normal Vite + React project.

## Run

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run: `npm install`
5. Run: `npm run dev`
6. Open the localhost address shown in the terminal.

## Main files

- `src/App.tsx` - all dashboard screens and functionality
- `src/index.css` - global CSS
- `src/main.tsx` - starts the React app
- `vite.config.ts` - simple Vite configuration
- `package.json` - required libraries

The dashboard uses React, Tailwind CSS, Recharts for charts, and Leaflet/React-Leaflet for the map.
